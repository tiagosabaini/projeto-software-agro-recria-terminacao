# Sistema de Gestão de Recria e Terminação Bovino

## Sobre o Projeto
O projeto consiste em um sistema de software voltado ao agronegócio, especificamente focado nas etapas de recria e terminação de gado de corte. O objetivo principal é resolver a falta de previsibilidade financeira e a dificuldade no controle de custos por arroba (@) ganha durante o processo de engorda.
