# 🐂 Sistema de Recria e Terminação Bovino

## 📌 Sobre o Projeto
O projeto consiste em um sistema voltado ao agronegócio, focado na gestão financeira e zootécnica das etapas de recria e terminação de gado de corte. O sistema resolve a falta de previsibilidade do produtor rural, permitindo o controle de custos por arroba (@) ganha e evitando a venda de lotes com prejuízo para o frigorífico.
